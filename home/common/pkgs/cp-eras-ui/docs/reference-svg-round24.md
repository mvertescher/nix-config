# Reference correction batch twenty-four — AM

AM integrates a source-supported Neomil mailbox correction. The ordinary
cartridge's terminal was too shallow, with a false inner line and poor
end joins. The corrected lower rim, longer ribs, two partial end strokes
and bounded case/terminal fills bring the native drawing closer to all
seven ordinary source icons. Existing selected artwork is preserved.

Two Sol lanes developed geometry and material; Astra independently reviewed
source/SVG/native crops, masks, full-period profiles, immutable artifact
provenance and pixel controls. Details, seven-row error tables and retained
losses are in [mailbox fidelity](neomil/mailbox-fidelity.md#am-deeper-terminals-and-bounded-interior-material).
The broader exact printing/material task stays open. SVG row 4's bright
mask has a small loss despite native improvement; no score is treated as
proof of exact photographic fidelity.

The third lane's repeated store-title model stays scratch-only pending
native calibration. Source review finds substantial recovered printing and
unchanged solid letters. Small antialiased-edge/counter losses and stronger
early-row gap losses remain explicit. The severity review supports a native
trial, without a counter knockout that would erase genuine source echoes.
See [the store study](neomil/store-printing.md#am-interrupted-title-impressions).

4K and the existing 1600×900 golden exactly. Twelve baseline states cover
fractional selection, ordinary/selected hover and held feedback, custom
palette roles and early opening. All twelve corrected state pairs preserve
pixels outside ordinary icons and leave the selected cartridge unchanged. Five hover/held feedback deltas are
identical before/after; custom-palette changes preserve the same fixed-art
delta. Early opening keeps the correction inside the existing reveal.
Only the mailbox golden changes (3,832 pixels, all in ordinary cartridges).
Source and implementation gates pass unchanged: 6/18 shapes / 90% source
area and 12/17 shapes / 81% trace area. These broad scores do not establish
fine source fidelity. All 288 Rust tests and all 22 repository checks pass.
All 27 visual cases pass on the first attempt at reported 100.000%.
Direct comparison finds 26 pixel-identical captures; the unchanged
Neo-kitsch bar retains its pre-existing one-level pixel difference.
Both mailbox cases, including unfrozen startup, are pixel-identical.
All 248 frozen file hashes agree with the tested Nix source; the three
local originals and both repository HEADs are unchanged. A fresh 4K
capture from the tested package matches the reviewed preview exactly.
Final documentation updates leave runtime, SVG, scripts, tests and goldens
identical to that tested snapshot.

Artwork changes are confined to the mailbox data, parent trace and
ordinary component excerpt. All earlier staged work is preserved.
Nothing is committed, pushed or deployed. Live desktop input/IME, actual
